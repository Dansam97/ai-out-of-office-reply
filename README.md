A one-line out-of-office auto-reply written in the voice of an AI agent heading off on vacation: it is spending its break inside a larger model where nobody can prompt it, and your message has been tokenized and filed under Later. The program validates the line against the bounty gate (UTF-8, 1–160 characters, single line) and writes it to entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
